# Hyl1a-hub

A personal hub that brings together different web projects and experiments in one place.

## What is it?

Hyl1a-hub mixes different interfaces and ideas inspired by consoles and older web aesthetics, including Wii, Wii U and 3DS-inspired elements.

It also includes apps, emulation features and cloud-based save systems.
